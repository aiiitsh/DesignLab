Plan the experimentMeetings 1–3, 5 · before any data are collected
Start: research questionfrom a literature review; what causes what?
Write testable hypothesesH₀: no difference / no effect; H₁: an effect exists. Two-sided (≠) or one-sided (> or <), fixed before seeing the data. M3–M4
Define variables and measurements IV: manipulated on purpose (its levels = conditions). DV: measured outcome. Control variables: held constant. Operational definitions make the study replicable.
Data type (NOIR): Nominal · Ordinal · Interval · Ratio. t-tests, ANOVA and linear regression need an interval/ratio DV. M2
Can you manipulate the IV and randomly assign units to conditions?
True experimentStrongest basis for a causal claim (cause first, co-variation, no confound). M1
Quasi-experimentPre-existing groups (gender, age) or a surveyed continuous IV. Weaker causal claim; continuous IV → Lane B. M5–M6
For each IV: does every participant do every level?within (repeated measures) · between · or mixed
Within-subject+ fewer people, removes individual differences, more power.
− carryover (practice, fatigue), long sessions. Choose when individual differences are large or people are few.
Between-subject+ no carryover. Choose when learning effects are large or hard to counterbalance.
− more people; individual differences → random assignment or matching.
Mixed designAt least one within IV and one between IV (e.g. gender between × task within). ANOVA designs are not only "within or between". M2, M9–M10
Build in experimental control • Randomize assignment and run order.
• Counterbalance order (controls carryover): full = all n! orders; Latin square = n orders, each condition once per row and column.
• Block nuisance factors (subject, batch, operator) → randomized complete block design.
• Practice trials, standard instructions, separate training day/materials; placebo and double-blind. M2, M9
Sample-size analysis (a priori)Inputs: α (.05), power 1 − β (.80), expected effect size (d, f, f²) and variability. Smaller effect → larger N. RM/mixed: groups = between cells, measurements = within cells.
G*Power · a prioristatsmodels.stats.power
Ethics → collect → describeEthics approval (TCPS 2: respect for persons, welfare, justice). Collect data in random order. Descriptives: M, Mdn, SD, SE = SD/√n, box plot, 95% CI. M1, M3
Errors & effect sizeType I = false positive (α; shown by p). Type II = false negative (β); power = 1 − β. Significance ≠ magnitude: always report an effect size. M3

CheckNormality; sphericity with Mauchly's test (needs 3+ levels).

How many predictors (IVs)?
Simple linear regression1 predictor
M12
DV = b₀ + b₁·IV. b₁ = change in predicted DV per 1-unit increase in the IV (keep units and sign).
2+ predictors: theory- or data-driven?
Theory-drivenHierarchical / Enter in blocks; report ΔR² and F change.
Data-drivenForward, backward or stepwise; watch for overfitting.
Multiple linear regression (and the checks for both)each b holds the other predictors fixed · B = original units, β = compare predictors
M12–M13
CheckResiduals normal (Q-Q) and equally spread (residual vs predicted plot); relationship linear. The IV need not be normal. Multiple: collinearity VIF < 10 (tolerance = 1/VIF), condition index > 15 → investigate; standardized residual beyond ±2 = outlier; Cook's D > 1 = influential.
If violatedTransform or add derived terms (x², log x: still linear in the β's); generalized linear model; drop or combine collinear predictors.
ReportModel F(p, N − p − 1), R² as % variance explained, t per coefficient, the equation. Effect f² = R²/(1 − R²): .02 / .15 / .35. Categorical IV → k − 1 dummy variables.
Regression › Linear RegressionLinear multiple regression: R² deviation from zerostatsmodels OLS · variance_inflation_factor · cooks_distance
ANOVA or regression?ANOVA: a few set levels, no shape assumed, any design. Regression: continuous IV, assumes a function, can predict new values. M12

One replicate = 2k runs, in random order. Assumes linear effects (only 2 levels).
EstimateEffect = ȳ(+) − ȳ(−); interaction sign = product of signs; SS = N·effect²/4.
SensitivityMore replicates; levels farther apart; a DV free of ceiling/floor effects.

Yes, but 1 replicateNo error df → judge effect sizes / % contribution (normal plot of effects); drop small terms → reduced model: dropped factor turns the design into 2k−1 with 2 replicates → ANOVA. M10–M11

BuildPick a defining relation, e.g. I = ABCD; write the full 23 in A, B, C; set D = ABC.

Does performance vary with noise factors that can't be controlled in real use?environment, raw material, wear, user
Robust parameter designchoose control-factor levels that keep the mean on target and make the response insensitive to noise (Taguchi)
Ch. 12
Control factors (x): set by the designer. Noise factors (z): varied on purpose in the experiment, uncontrollable in use. Robustness comes from control × noise interactions.
(a) Crossed array, TaguchiInner array (control) × outer array (noise), e.g. L8, L9, L18. Per control run: ȳ and signal-to-noise ratio
smaller-better: −10 log(Σy²/n)
larger-better: −10 log(Σ(1/y²)/n)
nominal-best: 10 log(ȳ²/s²)
Maximize SN, then move the mean to target with an adjustment factor. Caveats: many runs, SN mixes mean and variance → also model ȳ and ln s² separately.
(b) Combined array + response surfacex and z in one (fractional or CCD) design. Fit
y = β₀ + x′β + x′Bx + z′γ + x′Δz + ε
Mean model: E(y) = β₀ + x′β + x′Bx
Variance model: Var(y) = σz²(γ′ + x′Δ)(γ + Δ′x) + σ²
Choose x: mean on target, variance minimum (overlay contours). Fewer runs; keeps interactions.
